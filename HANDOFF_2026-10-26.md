# ap39 handoff, 2026-10-26

The site moved from ap39.crystllabs.com to **https://ap39.site** (owner's request). It is still this repo on
GitHub Pages, built by `.github/workflows/deploy.yml`.

## What is live (checked 2026-10-26 with curl and headless Chromium)

| Check | Result |
|---|---|
| `https://ap39.site/`, `/repo`, `/alpha`, `/contact` | 200, GitHub Pages, certificate `CN=ap39.site` valid to 2027-01-24 |
| `http://ap39.site/` | 301 to `https://ap39.site/` (Enforce HTTPS on) |
| `https://www.ap39.site/repo` | 301 to `https://ap39.site/repo` |
| `/robots.txt`, `/sitemap.xml` | 200 (new static files in `public/`) |
| Footer on every page | "Also by us: CrystlQuant - a number before the game, graded after." linking https://crystlquant.com/ |
| `https://ap39.crystllabs.com/<path>` | lands on `https://ap39.site/<path>`, query and hash kept |

## Pieces

- `public/CNAME`: `ap39.site`. `metadataBase` is `https://ap39.site` in `src/app/layout.tsx`.
- Alpha posts keep their canonical on `crystllabs.com/blog/<slug>.html` (see `src/app/alpha/[slug]/page.tsx`).
  They are left out of `public/sitemap.xml` for that reason.
- Namecheap DNS for ap39.site: four A records `@` to 185.199.108-111.153, CNAME `www` to `ap39.github.io.`,
  TXT `_github-pages-challenge-ap39` (GitHub domain verification, ap39.site shows Verified under the AP39
  account's Settings > Pages). The existing `oscar` A record (192.99.18.64) and email forwarding were left alone.
- The old address is the separate repo **AP39/ap39-redirect** (GitHub Pages, CNAME `ap39.crystllabs.com`). Its
  pages forward with a JavaScript redirect plus a meta refresh and a canonical to ap39.site. Do not delete it
  while the `ap39` record on crystllabs.com still points at GitHub, or the subdomain could be claimed by someone else.
- crystllabs.com links and its `ads.txt` were updated (CrystlLabs/crystllabs.com PRs #1 and #2).
- The repo list now spells the name `CrystlQuant` (`src/data/repo.json`).
